# 安装

OpenFlow 不在 Google Play / 国内应用商店上架，目前仅通过 GitHub Releases 分发已签名的 APK。

## 1. 选对 ABI

到 [GitHub Releases](https://github.com/hanklzl/OpenFlow/releases/latest) 页面，找到与你设备匹配的 APK 文件：

| 设备类型 | 文件名规则 | 何时选 |
|---|---|---|
| 真机（绝大多数手机/平板） | `OpenFlow-vX.Y.Z-arm64-v8a.apk` | **默认选这个** |
| Android 模拟器 / x86 平板 | `OpenFlow-vX.Y.Z-x86_64.apk` | 仅当确定设备是 x86_64 时 |

> 不确定自己设备的架构？打开「设置 → 关于手机 → 处理器」，或下载任意一个测试，装错会被系统拦下，不会留下残留。

每个 APK 旁边会附带 SHA256 校验值（在 Release Notes 的「构建产物」段）；如需校验完整性，将文件下载后对比：
```
shasum -a 256 OpenFlow-vX.Y.Z-arm64-v8a.apk
```

## 2. 允许「未知来源」安装

Android 默认禁止从浏览器安装 APK。打开下载好的 APK 后，如果系统提示「此应用来源不允许安装」：

1. 点击「设置」
2. 把当前浏览器（Chrome / 文件管理器）的「安装未知应用」开关打开
3. 返回继续安装

仅当本次安装需要时开启；安装完成后建议关闭。

## 3. 首次启动

打开 OpenFlow 后会进入 **「首次设置」引导页**，依次完成：

1. 授予 **无障碍服务** —— 让 OpenFlow 能感知输入框焦点、把文本写入光标。
2. 授予 **悬浮窗权限**（SYSTEM_ALERT_WINDOW）—— 让悬浮球能浮在其它 App 之上。
3. 授予 **麦克风** + **麦克风类型前台服务** —— 录音的必要权限。

详细的权限说明与定位每一项设置的路径，见 [权限引导]({% link permissions.md %})。

## 4. 下载一个 ASR 模型

权限齐备后，进入「模型」Tab，下载至少一个 whisper 模型才能开始用。详细的模型选型与体积说明见 [模型选型]({% link models.md %})。

## 升级与降级

OpenFlow 升级直接覆盖安装新 APK 即可，**不会丢失模型与设置**。

如果新版本崩溃或不可用，可在 Releases 历史里下载更早版本并覆盖安装。降级通常不会损失数据，但跨大版本降级（如 v1 → v0）不在保证范围内。

## 卸载

走系统标准流程：长按图标 → 卸载，或「设置 → 应用 → OpenFlow → 卸载」。

> 模型文件存放在 App 私有目录下，**卸载会一并清除**所有模型。若希望保留模型重装，可先在 App 设置中查看模型目录路径，手动备份。
